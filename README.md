# Общий Lua

Один редактор Lua на всех посетителей + общие модули (файлы) + чат с никами.

- Код и файлы общие: правки видят все в реальном времени.
- `require("utils")` подключает общий файл `utils.lua`.
- Lua выполняется в браузере (fengari), а не на сервере — сервер ничего не запускает.
- Лимит выполнения — 3 секунды, чтобы `while true do end` не вешал вкладку.
- Доступны стандартные библиотеки Lua 5.3: base, coroutine, table, string, utf8, math, os, io, debug, package.
- `io` работает с общими файлами редактора: `io.open("data.txt", "w")` создаёт файл у всех,
  `io.read` спрашивает ввод через окно браузера.
- `os.execute` — мини-эмуляция (echo, ls, cat, touch, rm, mv, cp, pwd, whoami, date) над общими файлами.
  Настоящие команды ОС не выполняются: это было бы дырой в безопасности. `io.popen` недоступен.

## Локально
    npm install
    npm start        # http://localhost:3000

## Деплой
1. Залей папку в репозиторий на GitHub.
2. Render → New → Web Service (или Blueprint, если используешь render.yaml) → выбери репозиторий.
3. Build: `npm install`, Start: `npm start`.

Бесплатный план Render засыпает без трафика, а файловая система временная:
после перезапуска/деплоя data.json пропадёт. Для постоянного хранения подключи Disk
и задай переменную окружения `DATA_FILE=/data/data.json`.

## Вкладка «Игра»
Ритм-игра в духе osu!mania: 4 дорожки, у каждой свой цвет и клавиша (D F J K, либо касание/клик по дорожке).
- Тонкая белая линия внизу, чёрный фон, кружки вместо нот.
- Редактор треков с таймлайном: музыка играет прямо в редакторе (можно замедлить до 0.5×), ноты записываются нажатием D F J K или цветных кнопок в такт музыке, либо ставятся касанием на таймлайне в любой момент (до миллисекунды). Есть сетка по BPM с привязкой, тап-темп, отмена, пресеты паттернов и тест-прогон.
- Ссылка на музыку — прямая ссылка на аудио (mp3/ogg/wav), играет во время игры. Ссылки на YouTube не работают.
- Скорость падения кружков не ограничена сверху (поле ввода, до 1000).
- Матчи: вызов конкретного игрока или всех сразу, очки соперника видны в реальном времени, есть реванш.
- Рейтинг: лучшие очки по каждому треку и общий рейтинг (сумма лучших очков по всем трекам).
- Игроки различаются только по нику, без паролей: очки на клиенте можно подделать. Сервер лишь отсекает значения выше теоретического максимума.

## Аккаунты
- Регистрация и вход по имени и паролю (кнопки в шапке). Пароли хранятся только в виде хеша scrypt, сессия — случайный токен на 30 дней.
- Имя аккаунта становится ником: в чате, матчах и рейтинге его нельзя подделать. Гость не может взять имя зарегистрированного игрока (к нему добавится «(гость)»).
- Без входа можно: править общий код и модули, писать в чат, играть и участвовать в матчах.
- Только после входа: сохранять треки и попадать в рейтинг. Править и удалять трек может только его автор; чужой трек можно сохранить как свою копию.
- Лимиты: 5 регистраций в час и 10 попыток входа за 10 минут с одного IP (и на одно имя).
- Аккаунты лежат в `data.json`. На бесплатном Render он стирается при перезапуске — для постоянного хранения нужен Disk (`DATA_FILE=/data/data.json`). Не коммить `data.json` в GitHub (он уже в `.gitignore`).

## Вкладка Doors
Кооперативный 3D-хоррор по мотивам Roblox DOORS (three.js с CDN, звук синтезируется в браузере). Все посетители сайта играют в одном забеге.
- Комнаты генерируются по seed от сервера, поэтому у всех одинаковые; дверь открывается сразу для всех. Цель — 100 дверей.
- Сущности приходят событиями с сервера: Вихрь (мигает свет, пролетает один раз и ломает свет) и Эхо (быстрее, несколько проходов туда-обратно). От них прячутся в шкафах. Все существа нарисованы оригинально.
- Шорох (клиентский): нужно успеть посмотреть на него, иначе укус.
- Погоня: после некоторых дверей (12, 28, 45, 65, 85) коридор из 5 комнат заполняют завалы и глаза на стенах, и по нему идёт Преследователь. Прятаться нельзя — нужно добежать до двери «0000» и открыть её. Скорость существа (6.2) чуть выше шага (4.2), но ниже бега (7.2).
- Обстановка: обои и панели, ковры с дорожкой, балки, люстры и бра, горшечные растения, книжные полки, столики с вазами, картины, шкафы и комоды с выдвижными ящиками.
- Запертые двери требуют ключ из ящика этой комнаты, тёмные комнаты — фонарик (F), золото в ящиках и на полу.
- Погибшие наблюдают за живыми; когда погибли все — новый забег.
- Чат внутри игры: кнопка 💬 в углу (или Enter / T). Это тот же общий чат, что и на вкладке «Код»; новые сообщения мелькают поверх игры.
- Управление: WASD, Shift, мышь (клик захватывает курсор), E, F. На телефоне: левая половина экрана — джойстик, правая — обзор.
- Столкновение с сущностью проверяет клиент, поэтому читерам это не помеха. Для кооператива без рейтинга это приемлемо.

## Вкладка «Шахматы»
- Полные правила (рокировка, взятие на проходе, превращение, мат, пат, правило 50 ходов, троекратное повторение, недостаточный материал). Движок — `chess.js`, проверен тестами perft; все ходы проверяет сервер.
- Игра против компьютера (3 уровня) или против другого посетителя: вызов конкретного игрока или всех сразу.
- Часы: без часов, 3, 5 или 10 минут на сторону. Сдача, предложение ничьей.
- Если связь оборвалась, у игрока есть 40 секунд, чтобы вернуться в партию (после перезагрузки страницы она восстанавливается).
- Рейтинг Эло (старт 1200) считается только в партиях между двумя вошедшими в аккаунт игроками.
- Игра с компьютером не влияет на рейтинг. Ход бота считается на сервере (до долей секунды на сложном уровне).
