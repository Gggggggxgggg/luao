# Свои текстуры блоков (необязательно)

По умолчанию все текстуры OneBlock рисуются кодом. Чтобы заменить любую из них, положи сюда PNG с таким именем
(квадратный, например 16×16 или 64×64) — игра подхватит файл сама, ничего больше менять не нужно:

grass_top, grass_side, dirt, stone, cobblestone, sand, log_side, log_top, planks, glass, bricks,
table_top, table_side, table_front

Например: `public/textures/dirt.png`. Используй только те файлы, права на которые есть у тебя.
